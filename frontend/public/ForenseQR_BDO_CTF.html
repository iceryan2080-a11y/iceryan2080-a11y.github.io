Resumen Ejecutivo

Durante el desarrollo del CTF organizado por BDO (duración: 3 días), se presentó como evidencia una fotografía de una hoja impresa conteniendo un código QR parcialmente dañado — simulando el hallazgo de un documento físico sustraído de una oficina. La esquina superior derecha del código QR estaba físicamente ausente (papel rasgado), eliminando el tercer Position Detection Pattern y parte de los módulos de datos adyacentes.

Mediante análisis forense digital y reconstrucción manual de los módulos dañados, se logró recuperar íntegramente el payload del QR:

03
Metodología

El proceso siguió las fases de respuesta a incidentes definidas en NIST SP 800-61 Rev.2: Preparación → Detección → Contención → Erradicación → Recuperación → Lecciones aprendidas.

01
Adquisición y Preservación
Se calcularon SHA-256 y MD5 de la imagen original antes de cualquier procesamiento. Se trabajó exclusivamente sobre copias de trabajo.
02
Identificación del Daño
El tercer Position Detection Pattern estaba completamente ausente. Se detectó una franja diagonal de datos dañada en rows 0–10, cols 8–21, con densidad de módulos de apenas 7–29% (esperado: ~50%).
03
Fingerprinting del QR
Versión 3 (29×29 módulos, mod_size ≈ 15.7 px). Se midió el finder pattern superviviente para calibrar con precisión subpíxel. Se identificó el alignment pattern en (22, 22).
04
Reconstrucción Estructural
Se redibujaron manualmente: (a) el finder pattern faltante 7×7, (b) los separadores blancos adyacentes, (c) el timing pattern en fila/col 6.
05
Brute-force de Format Information
Con ambas copias del Format Info destruidas, se iteraron las 32 combinaciones posibles (4 niveles EC × 8 máscaras). Máscara 4 + EC Level L produjo el único resultado coherente.
06
Extracción del Payload
Decodificación final con alignment pattern excluido del data stream (error crítico corregido). Reed-Solomon permitió recuperación del 100% del payload.

Clasificación TLP
🔴 TLP:RED

Uso exclusivo del receptor designado. Aplicar si el QR contenía clave privada, token activo, magic link o credencial de producción. El payload debe ser tratado como secreto hasta su rotación.

🟡 TLP:AMBER

Distribución limitada al equipo de seguridad. Permite coordinar remediación sin exponer contenido a terceros. Apropiado para este incidente.

06
Recomendaciones de Remediación
🔄
Rotación inmediata de secretos
Invalidar y regenerar cualquier recurso vinculado al QR. No basta con destruir el papel — el código ya fue recuperado.
📷
Política de fotografía
Prohibir fotos en zonas con QRs de acceso o pantallas con credenciales. Señalización visible y entrenamiento al personal.
🚫
Eliminar el blur como ocultación
Los filtros blur en QRs son reversibles con IA. Usar siempre un bloque sólido opaco — nunca desenfoque.
🔐
Usar EC Level H en QRs críticos
Nivel H (30% restauración) dificulta reconstrucción parcial al distribuir más codewords de paridad en el símbolo.
🧾
Registro con expiración
Inventariar QRs emitidos con fecha de expiración. Un QR estático sin TTL es un vector permanente si se filtra.
🔍
Monitoreo de accesos
Revisar logs desde la fecha del evento para detectar uso no autorizado del recurso apuntado por el QR.

7.3 Bug Crítico — Alignment Pattern

El alignment pattern (5×5 módulos en posición [22,22]) no estaba siendo excluido del data stream, corrompiendo 25 módulos de datos y produciendo basura en los bytes 10–35.

Python · ISO/IEC 18004:2015 §6.3.6
# ❌ Sin excluir alignment — bytes 10-35 = garbage
data_stream.append(grid[row][col])  # incluye alignment

# ✅ Correcto: excluir función modules del data stream
if 20 <= row <= 24 and 20 <= col <= 24:
    return True  # alignment pattern → función, NO dato
08
Conclusiones

El análisis forense demostró que es posible recuperar íntegramente el contenido de un código QR parcialmente destruido, incluso cuando se pierden elementos estructurales críticos como el Position Detection Pattern. La combinación de reconstrucción manual, brute-force de Format Information y corrección Reed-Solomon permitió extraer el payload completo.

⚠ Destruir parcialmente un documento que contiene un QR de acceso NO es suficiente. Se requiere destrucción completa e irreversible del documento más rotación inmediata del secreto asociado.
